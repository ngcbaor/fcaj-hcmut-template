## Technical Blogs Overview

During the First Cloud AI Journey (FCAJ) program, I authored and published 3 technical blog posts on the official [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community. These articles share practical engineering insights, architectural patterns, and hands-on experiences gained while building the awsplace real-time cloud application.

### Published Blogs Summary

#### 1. [Blog 1 - Real-time Canvas Communication on AWS using WebSockets and ECS Fargate](3.1-blog1/)
This blog introduces real-time full-duplex communication patterns on AWS using WebSockets and containerized Go microservices on ECS Fargate. It explains connection lifecycle management, thread-safe update broadcasting, origin validation security, and scaling low-latency real-time canvas architectures.

#### 2. [Blog 2 - High-Performance Shared Storage for Containers with Amazon EFS](3.2-blog2/)
This blog explores Amazon Elastic File System (EFS) as a scalable, POSIX-compliant shared file storage solution for containerized workloads. It covers performance tuning, access points, throughput modes, and persistent storage strategies for multi-task ECS deployments.

#### 3. [Blog 3 - Modern Infrastructure as Code for Cloud Applications with AWS CDK](3.3-blog3/)
This blog focuses on modern Infrastructure as Code (IaC) principles using AWS Cloud Development Kit (CDK). It demonstrates how to define production-ready cloud stacks (VPC, ECS Fargate, DynamoDB, S3, ALB) using programmatic TypeScript constructs instead of static CloudFormation templates.
